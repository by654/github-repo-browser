    受浏览器安全策略限制，GitHub 不允许其登录页被嵌入其他网页，也无法在纯前端安全地完成 OAuth 换取 Token。 请按下面三步操作。

    1. 打开 GitHub 登录页
      在弹出窗口登录你的 GitHub 账号
    2. 创建 Personal Access Token
      建议只勾选必要权限
    3. 粘贴 Token 并保存
      格式通常为 ghp_… 或 github_pat_…
      ✓本机已保存 Token，下次打开自动填入。

    🔒 Token 使用 AES-GCM（随机盐 + PBKDF2 200k 迭代）加密后保存在本机 localStorage，不会上传到任何服务器。

    当所在地区访问 GitHub 受限或遇到限流时，可切换代理源获取仓库原始内容（raw 文件、图片等）。 API 请求始终直连 GitHub，代理仅用于内容分发。
