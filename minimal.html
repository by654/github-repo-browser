获取 GitHub Token

受浏览器安全策略限制，GitHub 不允许其登录页被嵌入其他网页（X-Frame-Options: deny）， 也无法在纯前端安全地完成 OAuth 换取 Token。请按下面三步操作，全程不会离开本页。

  1. 打开 GitHub 登录页
    在弹出窗口（或新标签页）中登录你的 GitHub 账号
  2. 创建 Personal Access Token
    建议只勾选必要权限，创建后页面会一次性显示 Token
  3. 粘贴 Token 并保存
    格式通常为 ghp_… 或 github_pat_…

🔒 勾选后 Token 会以明文保存在您本机的浏览器 localStorage 中，仅当前浏览器可读取，不会上传到任何服务器。请勿在公共电脑上使用此项。
若只浏览公开仓库，其实无需 Token（未登录限额 60 次/小时）；填写 Token 可提升至 5000 次/小时。
